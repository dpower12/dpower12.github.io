Thanks to REPENTOGON, custom item pools can be defined within itempools.xml. Epiphany has numerous features that take advantage of these custom pools. This page features details for all of Epiphany's item pools, with links to the [official Epiphany wiki](https://tboiepiphany.wiki.gg/wiki/TBOI:_The_Epiphany_Mod_Wiki) that contain the contents of said pools.
